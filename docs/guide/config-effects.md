# Config switch effects

Every runtime switch in spawn's service configs, with evidence for what it actually changes. Captured switches were driven by `scripts/config-switch-gifs/generate.py` against a real service on a temp SQLite store: the pipeline boots the binary once per state (off/on), performs the same real HTTP request, and hard-fails unless the observed behavior matches the expected off/on difference — the pipeline doubles as a config regression test. Switches whose effect needs a multi-service stack, unfolds over time, or lives on the deployment side are not faked with screenshots; they are listed in the manual verification checklist at the bottom.

- Config: `Coupon.LockTtlSeconds / ReleaseIntervalSeconds`

## Regenerate

Edit [switches.json](https://github.com/cuihairu/spawn/blob/main/scripts/config-switch-gifs/switches.json) first, then rerun:

```bash
python3 scripts/config-switch-gifs/generate.py --all   # capture + stitch GIFs
python3 scripts/config-switch-gifs/render_docs.py        # regenerate both doc pages
python3 scripts/config-switch-gifs/generate.py --check   # artifacts/manifest/docs consistency gate
```

Frame-difference gate: if the off and on final frames come out identical, the switch effect was not observable and the pipeline fails instead of producing a fake image. See [manifest.json](/config-switch-gifs/manifest.json) for the artifact contract (repo-relative paths).
