## 📖 功能展示

### 攻略浏览
```
/guides → 查看所有攻略
  ├── 全部攻略 (tab)
  ├── 我的攻略 (tab, 登录后可见)
  └── 创建攻略 (button, 登录后可见)
```

### 攻略详情
```
/guides/:id → 攻略完整内容
  ├── 标题、作者、时间
  ├── 标签列表
  ├── 正文内容
  ├── 点赞和统计
  └── 评论系统
```

### 攻略创建/编辑
```
/guides/new 或 /guides/:id/edit
  ├── 游戏 ID (可选)
  ├── 标题 (必填)
  ├── 内容 (必填)
  ├── 标签 (可选)
  └── 保存草稿 / 保存并发布
```

### 评论互动
```
评论系统
  ├── 发表评论
  ├── 回复评论 (嵌套)
  ├── 点赞评论
  └── 删除评论 (作者)
```

## 🎨 设计原则遵循

### KISS (Keep It Simple, Stupid)
- 组件结构清晰简单
- API 调用逻辑直观
- 样式命名规范一致

### DRY (Don't Repeat Yourself)
- 复用评论组件
- 统一的样式变量
- 共享的类型定义

### 单一职责原则
- 每个组件功能专一
- API 函数职责明确
- 样式文件按功能组织
